# 依頼文の型

窓口から実行側の受付へ送る依頼文の型です。文章で書き、コマンドや実行手順は埋め込みません。

```text
＜達成すること＞をしてください。

対象：＜作業場所・ファイル・サービス＞
完成条件：＜何がどうなっていれば終わりか＞
使ってよいモデル：＜割り当ての指定があれば＞
制約：＜変えてはいけない物、やってはいけないこと＞

終わったら、変更点・検証結果・残る問題を短くまとめて返してください。
```

## 書き方

- 1件の依頼に1つの成果を入れます。複数の成果は分けます。
- 完成条件は「確かめられる形」で書きます（例：「保存して読み戻し、件数が一致すること」）。
- 本人の言葉でなければ進めない事項（金銭、外部への送信・投稿、削除、秘密情報）は、依頼文に含めず、本人の直接確認に回します。
- 返事への追記がある場合は、同じ受付番号への追記として送ります。窓口側は追記も新しい到着として扱います。
