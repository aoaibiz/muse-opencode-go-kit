# クライアント台帳の例

[クライアント台帳](../docs/CLIENT-LEDGER.md) の型の実例です。名前・店舗・金額はすべて架空の例です。

## 台帳（INDEX.md）の例

```markdown
# クライアント台帳

| クライアント | 店舗・会社 | サービス | 状態 | ファイル |
|---|---|---|---|---|
| 山田はな（架空） | カフェ・ルナ（架空） | SNS 投稿サービス | 運用中 | ~/memory/clients/example-cafe.md |
```

## クライアントファイルの例

```markdown
# クライアント: 山田はな（カフェ・ルナ）※架空の例

## 会社・店舗
- カフェ・ルナ（架空）。SNS は Instagram と Threads。

## 担当者
- 山田はな（本人）。人としての情報は人物ファイル側。

## 契約内容
- SNS 投稿サービス。金額の条件は契約書の確認が取れていないため未確認（本人の発言だけで断定しない）。

## 使うサービス
- 投稿サービス本体（対象は Instagram・Threads）。

## 運用状態
- 計画は保存済み。毎日投稿の設定に移行中。写真と投稿の対応づけは確認中。

## 窓口・接続
- 連絡はメッセージアプリ（返信は利用者本人が行う）。
- 同意済みの範囲：計画の保存と確定まで。公開は本人の確認後。

## 注意
- 返信をエージェントから送らない。
```
