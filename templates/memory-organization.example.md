# 記憶の目次とシーンの例

[記憶の整理](../docs/MEMORY-ORGANIZATION.md) の型の実例です。名前・内容は一般化した見本です。

## 本体（MEMORY.md）の例

```markdown
# MEMORY.md

## 超重要事項
- 利用者は ○○（呼び方は「○○」）。実名は正式な文脈でのみ使う。
- 私は窓口＝司令塔。設計の最終判断は上位モデルか利用者に置く。
- 報告は、結果が本番に反映され自分で確かめてから、短く。本人の判断が要る物だけ先に出す。
- 本人の直接の言葉が要る物：金銭、外部への送信・投稿、削除、秘密情報。

## 目次（シーン別ファイル）
- `~/memory/scenes/work-rules.md` — 仕事の進め方・好みのルール集。読む時：あらゆる成果物・報告・依頼の仕事の開始時。
- `~/memory/scenes/clients.md` — クライアント運用の入口。読む時：クライアント対応の開始時。ここから ~/memory/clients/INDEX.md を引く。
- `~/memory/scenes/services.md` — 運用中サービスの状態と決まり。読む時：そのサービスの確認・投稿・運用の開始時。
```

## シーン別ファイルの先頭の例

```markdown
# シーン: クライアント運用

読む時: クライアント対応の開始時。まず ~/memory/clients/INDEX.md で該当クライアントを引き、その人のファイルを読む。「人」としての情報は ~/memory/people/ 側にある。
```
